TUTOR TEST - how to run it
==========================

What it does
  Tries small AI models on this computer and measures how fast and how well
  they explain common beginner Python mistakes. Nothing is sent anywhere:
  the models run on this computer. At the end it opens a report in your browser.

Before you start
  - About 20 GB of free disk space (two models, sometimes in more than one
    version; the program offers to delete them at the end).
  - A good internet connection for the downloads.
  - Plug in the laptop: the test keeps the processor busy for a while.
  - Allow 30 to 60 minutes, mostly downloading. You can leave it running.

Windows
  1. Right-click the zip file and choose "Extract All...". Keep every file
     together in the same folder.
  2. Open the folder and double-click tutor-test.exe.
  3. If Windows shows "Windows protected your PC", click "More info",
     then "Run anyway". (This appears once because the program isn't from
     the Microsoft Store.)
  4. A black window shows progress. When it's done, the report opens in
     your browser and the window asks whether to delete the downloaded
     models. Type y and press Enter to free the disk space, or just press
     Enter to keep them.
  5. Send the folder named "reports" (next to the program) back to Andy.

Mac (Terminal)
  Go INTO the unzipped folder (the one that contains tutor-test and the
  .dylib files), then:
    chmod +x tutor-test
    xattr -dr com.apple.quarantine .
    ./tutor-test
  (GitHub's zip drops the "can run" flag, hence chmod. Run xattr only inside
  this folder, not in a parent folder.)

To stop early press Ctrl+C. A report of what finished is still written.

Options (for Andy): run with --help to see them, e.g.
  tutor-test --with-14b         also try the 14B coding model (big, slow)
  tutor-test --all-variants     try both the processor and graphics versions
  tutor-test --list             show every model in the catalog
